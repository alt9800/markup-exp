WebAR ベンチマーク

「カメラ映像に何かを重ねる」を、アプローチ別に比べるためのデモ集。 上の3つはカメラAPIと画像処理のみ(iPhone / Android)、 最後の1つはWebXR(Android Chrome)。

ドア認識

ドアの矩形を認識して枠を表示し、ボールを出力する。 実寸の仮定から距離を逆算し、3Dオブジェクトとして空間に置く。 トラッキングは回転のみ(3DoF)なので、歩くとずれる。

iPhone / Android

ワイヤーフレーム

カメラに映った輪郭を毎フレーム検出し、線として発光表示する。 画面空間エフェクト: 毎フレーム画像から計算し直すため、対象からずれない。 そのかわり3Dの奥行きは持たない。

iPhone / Android

水辺のライン認識

水面と岸の境界ラインを毎フレーム検出し、そこから光の粒を立ち上らせる。 ラインは画面空間、粒子は寿命つきのアニメーション。両者の組み合わせ。

iPhone / Android

WebXR immersive-ar

OSのトラッキング(SLAM / 6DoF)で縦平面を認識して枠とボールを表示する。 配置後のオブジェクトは空間に固定され、回り込んでも位置が保たれる。

Android Chrome
すべて静的ファイルのみ・サーバーサイドなし。 カメラ利用のため、localhost以外ではHTTPSでの配信が必要。
