
以下のような雑実装

カメラ: getUserMedia の <video> を背景に敷き、透過A-Frameキャンバスを重ねるオーソドックスなWebAR構造
マークアップ: ドア枠は <a-box> 3本 + <a-plane>(開口部)をHTMLで宣言。ボール放出・グローは自作コンポーネント(ball-fountain / glow-pulse)を属性として付けるだけ
ドア認識: Sobel縦エッジ→列ヒストグラムのピーク対→上辺の横エッジ確認、という約26行の「素朴な推論」。MLもSLAMも不使用。誤検出時は画面タップで配置にフォールバック
距離推定: 「ドアの実寸=高さ2m」という仮定+ピンホールモデルで逆算(検証で理論値と一致)。単眼では絶対スケールが決まらない、という限界をそのまま教材化
空間固定: 検出時のカメラ姿勢でワールド座標に焼き付け、以後はDeviceOrientation(3DoF)で追従。iPhone Safariでも動くのがWebXR版に対する最大の強み
