WebAR ベンチマーク

「カメラ映像に何かを重ねる」を、アプローチ別に比べるためのデモ集。 上の3つはカメラAPIと画像処理のみ(iPhone / Android)、 最後の1つはWebXR(Android Chrome)。

ドア認識

ドアの矩形を認識して枠を表示し、ボールを出力する。 実寸の仮定から距離を逆算し、3Dオブジェクトとして空間に置く。 トラッキングは回転のみ(3DoF)なので、歩くとずれる。

iPhone / Android

ワイヤーフレーム

カメラに映った輪郭を毎フレーム検出し、線として発光表示する。 画面空間エフェクト: 毎フレーム画像から計算し直すため、対象からずれない。 そのかわり3Dの奥行きは持たない。

iPhone / Android

水辺のライン認識

水面をひとつの面(領域)として認識し、その上端の水際から光の粒を立ち上らせる。 認識位置は水面をタップして指定し直せる。

iPhone / Android

WebXR immersive-ar

OSのトラッキング(SLAM / 6DoF)で縦平面を認識して枠とボールを表示する。 配置後のオブジェクトは空間に固定され、回り込んでも位置が保たれる。

Android Chrome
すべて静的ファイルのみ・サーバーサイドなし。 カメラ利用のため、localhost以外ではHTTPSでの配信が必要。

WebAR 벤치마크

"카메라 영상에 무언가를 겹치는" 방법을 접근법별로 비교하는 데모 모음. 위의 3개는 카메라 API와 이미지 처리만 사용(iPhone / Android), 마지막 1개는 WebXR(Android Chrome).

문 인식

문의 사각형을 인식해 프레임을 표시하고 공을 쏟아낸다. 실제 크기 가정에서 거리를 역산해 3D 오브젝트로 공간에 배치한다. 트래킹은 회전만(3DoF)이므로 걸으면 어긋난다.

iPhone / Android

와이어프레임

카메라에 비친 윤곽을 매 프레임 검출해 발광하는 선으로 표시한다. 화면 공간 이펙트: 매 프레임 이미지에서 다시 계산하므로 대상에서 어긋나지 않는다. 대신 3D 깊이는 갖지 않는다.

iPhone / Android

수면 인식

수면을 하나의 면(영역)으로 인식하고, 그 물가에서 빛의 입자를 피워 올린다. 인식 위치는 수면을 탭해서 다시 지정할 수 있다.

iPhone / Android

WebXR immersive-ar

OS의 트래킹(SLAM / 6DoF)으로 수직 평면을 인식해 프레임과 공을 표시한다. 배치된 오브젝트는 공간에 고정되어 돌아서 봐도 위치가 유지된다.

Android Chrome
모두 정적 파일만 사용, 서버 사이드 없음. 카메라 사용을 위해 localhost 이외에서는 HTTPS 배포가 필요.

WebAR Benchmark

A set of demos comparing approaches to overlaying content on a camera feed. The first three use only the camera API and image processing (iPhone / Android); the last one uses WebXR (Android Chrome).

Door detection

Detects a door rectangle, draws a frame, and spills out balls. Distance is back-solved from a real-size assumption and the object is placed in 3D. Tracking is rotation-only (3DoF), so it drifts when you walk.

iPhone / Android

Wireframe

Detects contours in the camera image every frame and draws them as glowing lines. A screen-space effect: recomputed from the image each frame, so it never drifts — but it has no 3D depth.

iPhone / Android

Water surface

Recognizes the water surface as a region and raises particles of light from the water's edge. Tap the water to re-anchor the recognition.

iPhone / Android

WebXR immersive-ar

Uses OS tracking (SLAM / 6DoF) to detect a vertical plane and show the frame and balls. Placed objects stick to space and stay put as you walk around.

Android Chrome
Static files only, no server side. HTTPS is required for camera access anywhere other than localhost.
